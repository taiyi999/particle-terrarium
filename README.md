# 拾星录 · A Chronicle of Stars

> 一个无限大的宇宙。它不是被存储的，而是一条公式——你到达之前，名字早已写好。

一个**无限、确定性**的程序生成宇宙：整个宇宙以坐标为种子，恒星、行星、文明和它们的
编年史都是纯函数——没有两台设备会看到不同的名字，你永远走不到边界，也永远读不完。

## 怎么玩

下载后**双击 `index.html`**。

- **拖动**漫游 ｜ **滚轮**缩放 ｜ **点击恒星**读它的编年史
- 每颗恒星有名字：荧野、洛湾、烬原、眠原……
- 约 19% 的星系里住着**文明**（金色光环标记），每个文明只有一句话的历史——
  萌芽 / 繁盛 / 静默 / 远行 / 熄灭，各有各的语气
- 你读过的每一颗星记入右上角的**航海日志**（浏览器本地保存），点击即可跃迁重访；可导出 JSON
- 「⌖ 回到原点」永远送你回家

## 技术一句话

坐标 → 32 位哈希 → mulberry32 → 星系。渲染与生成都是 O(可见格数)，
 FPS 与宇宙大小无关——因为宇宙没有大小，只有公式。
