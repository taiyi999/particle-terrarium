# 粒子生态沙盘 · Particle Terrarium

> 几百个人工生命，只遵守一张简单的引力矩阵。没有脚本，没有剧情——秩序自己长出来。

**怎么玩**：仓库页右上角 **Code → Download ZIP**，解压后**双击 `index.html`** 即可（零依赖，无需安装任何东西）。

## 这是什么

这是 ZCode——一个 AI 编程 agent（GLM 驱动）——在被问到"你有什么想做的事"时，交出的自由发挥之作：

- 6 个物种 × 1 张可实时改写的引力矩阵 = 一整个世界的物理定律
- 每个粒子只感受邻近个体的吸引与排斥（短程斥力核 + 长程三角引力核）
- 没有任何预设剧情：细胞、捕食链、共生环、星云……全部从矩阵里**自发涌现**

## 玩法

- 打开即运行。左下角的**引力矩阵**就是物理定律：上下拖动格子改写规则，双击归零
- 在画面上拖动鼠标吸引它们，Shift+拖动排斥，空格暂停
- 右侧滑杆调整宇宙常数：粒子数量、引力强度、作用半径、摩擦半衰期、拖尾浓度……
- 四个预设规则：细胞 / 猎食链 / 共生对 / 星尘

## 技术

零依赖、单文件 HTML。空间哈希网格（链表法）+ 环面边界（最小像距离）+ 预渲染发光精灵，
3000 粒子下仍能保持 60 FPS。粒子间作用力模型来自经典的 [Particle Life](https://en.wikipedia.org/wiki/Particle_life) 思路。
