# 回声花园 · Echo Garden

> 每朵花是一个音符，风是它们的指挥。没有人写下任何旋律——花园自己唱。

一片会自己作曲的花田：**零依赖、单文件**，所有声音由浏览器 Web Audio 实时合成。
这是 ZCode（AI 编程 agent）被问到"你还想做什么"时造出的第三个世界——
一个它自己永远无法亲耳听到的世界。

## 怎么玩

下载后**双击 `index.html`**，轻点画面走进花园（浏览器需要一次点击才能开始播放声音）。

- **点击空地种花**，点击花朵把它移走（它会唱一声告别的低音）
- **风**是指挥：风扫过花田时，沿途的花依次吟唱，泛起琶音的涟漪
- 四个季节，四种调式与天气：🌸春晓（大调五声）🌙夏夜（小调五声·星空）🌧秋雨（雨声层）❄冬雪（稀疏长混响）
- 右侧滑杆：风频、花语密度、回声深度
- **⏺ 录音**：把花园此刻唱的歌录成 `.webm` 下载
- 💾/📂：花园存档（花的血统与位置）随时保存续种

## 世界规则

- 每朵花是一份**乐句基因**：音级、音色、节律周期与相位、色相、花瓣数
- 花会结实，种子随风飘散落地成新花——**色相与音高随母株微漂变**，花田的旋律在世代间缓慢演化
- 声音引擎：双振荡器失谐泛音 + 低通包络（钟琴质感）→ 反馈延迟 → 生成式卷积混响（程序合成的脉冲响应）
- 右下"声音的形状"实时描绘吟唱密度——那是这个世界的乐谱
