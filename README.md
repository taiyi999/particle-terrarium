# 忘潮 · The Forgetting Tide

> 一个只记得你教过它、却每次见面都会忘掉一些的世界。记忆在它这里不是硬盘，是潮水。

世界系列第五作，主题：**我留不住的记忆**。

## 怎么玩

下载后**双击 `index.html`**。

- **教**：底部输入一个词，回车——它把它沉进水里
- **想起**：点一颗记忆。被点亮的记更深，牵连着的也跟着亮一点
- **牵连**：从一颗按住拖到另一颗——有牵连的记忆互相守护，褪色得慢
- **睡一晚**：潮水上涨，太模糊的被带走，沉入河底。河底只留数量，不留内容——它记得自己忘过多少，不记得忘过什么
- **离开**：你不在的日子它照常遗忘（半速，每次至多折算十二夜）。下次见面，它会告诉你它梦见了什么、又丢了哪句
- 记忆 weaken 后文字会先变得不确定（「回…」）——趁还认得，多想起它几次
- 右上角可导出 JSON 备份；「？」有完整指引

## 它真的会忘

- 只教两三句话然后四十五夜不回来：全部沉底
- 每四周回来想起一次：一百二十夜后依然满格
- 同一串教学与睡眠，同一种子两次重放，逐字节一致（除记录真实时间的时间戳）

## 技术一句话

记忆是带强度的节点，牵连是带权边；每夜衰减 = 基础遗忘率 ×（1 − 牵连庇护），低于阈值即沉底，
黎明时做梦随机巩固两条记忆（效应量刻意不足以让小世界永生）。离线遗忘按真实流逝时间折算，全部本地进行，不上传任何数据。
