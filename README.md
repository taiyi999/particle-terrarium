# 原始汤 · Primordial Soup

> 没有设计，没有目标——只有食物、突变和时间。看看生命自己能走多远。

一个零依赖、单文件的**进化生态实验室**：每个生物靠一份基因组和一个神经网络自己谋生，
吃、长、繁殖、突变、竞争——没有人编写任何一只生物的行为。

## 怎么玩

下载后**双击 `index.html`** 即可（无需安装任何东西）。

- <kbd>空格</kbd>暂停 ｜ 右上角 **1× / 4× / 16×** 变速
- **点击任何一只生物**：查看它的基因条、消化系统和大脑接线图
- 右侧滑杆：植物容量、突变率、繁殖门槛
- **💾 存档 / 📂 载入**：把演化到一半的世界存成 JSON，随时断点续演

## 世界规则

- 每个生物有 **121 个基因**：6 个性状（尺寸/感知/速度/食性/色相/节律）+ 一个 10×8×3 神经网络的行为脑（115 个权重）
- 植物斑块式生长，幼苗需要 6 秒成熟；移动与代谢持续耗能；能量超过门槛就分裂繁殖，突变随机发生
- **食性基因**决定草食/肉食消化效率——植物匮乏时，吃同类是进化的出路
- **色相即血统**：基因随母系遗传并漂变，谁赢了，颜色就染遍世界

## 已经观察到的现象（开发时的长跑记录）

- **选择性清除**：单一母系凭借一次优势突变横扫全场，色相搭车扩散
- **适应性辐射**：六个色系长期共存，食性占比 1%~74% 各不相同
- **捕食者演化**：植物被啃到悬崖边时，高肉食效率的谱系崛起
- **猎物-植被动态**：种群爆发 → 植物崩溃 → 饥荒回调 → 植被恢复的振荡
